saying.util.extract_sql_data(text, *, bytes_decoder=<method 'decode' of 'bytes' objects>)[source]

Extracts data from sql dump text.

Note: rows are split on the literal ),( separator, so rows separated by whitespace/newlines (as in the dump below) are not split apart. Correcting that parsing is a known limitation, kept here so the example reflects the actual current output.

>>> text = '''
... -- MySQL dump 10.13  ...
... ...
... INSERT INTO `quotes` (col1,col2,col3) VALUES
... (1,'One', 1.0),
... (2,'Two', 2.0),
... (3,'Three', 3.0);
... '''
>>> extract_sql_data(text)
[['1', "'One'", '1.0)', '(2', "'Two'", '2.0)', '(3', "'Three'", '3.0']]
